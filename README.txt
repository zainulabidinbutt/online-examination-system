# ExamPro — Online Examination System

A frontend-only online examination and quiz platform built with:
- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage

## Features
1. Student registration and login
2. Exam categories
3. Question CRUD (Admin demo)
4. MCQ examinations
5. Countdown timer
6. Automatic result calculation
7. Result history
8. Admin dashboard for questions, students and results
9. Responsive design

## Run
Open `index.html` in a browser.

## Admin
On the login screen, click "Admin demo".

## Important
This is a frontend/demo implementation. Accounts, questions and results are stored in the browser's localStorage. A real production online examination system should use a backend database and secure authentication rather than storing passwords client-side.
